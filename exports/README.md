# 変電所 地域別CSV

自動生成: 2026-11-06（`scripts/export_substations.py --by-pref`。元データ生成 2026-11-06）。毎月の座標更新のたびに作り直されます。

各都道府県の全変電所（全ランク）を系統スコア順に並べたCSVです。Excelでそのまま開けます。「系統ランク」「上位系の確認」列でフィルタしてください。

地図モード（substation.html#map）と同じ判定の列も入っています：「カテゴリ（地図の色）」（緑＝両方空きあり／黄＝変電所は空きあり・上位系は不明／紫＝変電所は空きあり・上位系は空き無し＝要接続検討／赤＝変電所単体で空き無し／灰＝データ無し）と「変電所単体の空き」「上位系の空き」「上位系統の判定理由」、「要接続検討」（○＝紫）、「接続検討の実績（件数・分類）」（対策なし／バンク等の対策待ち／上位系対策あり／記載なし、うち変電所は推定）、「上位側の送電線（相手側・上位側の空き）」、「上位系の制約設備（▼＝空き0以下）」。つながりの元は東北・北陸・関西・中国・四国・九州・北海道の公表物で、東京・中部・沖縄は「対象外エリア」になります。

**系統ランク（80点満点）の凡例**（CSVの「系統ランクの意味」列にも同じ文言）

| ランク | 意味 |
|---|---|
| S | 系統スコア60点以上（最優先で接続検討を申し込む） |
| A | 系統スコア48〜59点（接続検討の候補） |
| B | 系統スコア36〜47点（近くにS・Aが無いときの次点） |
| C | 系統スコア35点以下（見送り推奨） |
| データ無 | 送配電事業者の空容量が未公表・未取得で採点できない |

「上位系0の警告」列の「警告」は、空容量(上位系考慮)が2MW未満かつN-1電制が「可」でない変電所です（ランクとは別。工期が長くなりやすい）。

**判定(高圧2MW)の凡例**（v2・2026-11-06〜。CSVの「判定の理由」列に変電所ごとの根拠）

| 判定 | 意味 |
|---|---|
| 接続検討OK | 変電所単体（配電用バンク）に空きがあり、上位系も空きあり（または未公表）。接続検討を申し込む |
| 要検討 | 変電所単体は空きありだが上位系の空き無し（高圧2MWは実績でほぼ連系可だが工期が長く出力制御あり）、または配電用変電所でない。人が工期・出力制御・近くの別候補と比べて判断する |
| 接続検討NG | 変電所単体（配電用バンク）の空容量が2MW未満で空き無し。別の変電所を探す |
| データ無 | 空容量が未公表で判定できない。送配電事業者の公表資料か接続検討で確認 |
