- 「特定不可」は同じ名前の変電所が複数あり、電圧・設備容量でも1つに決められなかった行です（書き換えていません）
- 「本体に無い公表行」は公表CSVにあって本体リストに無い変電所です（座標などが無いため自動では追加しません）
