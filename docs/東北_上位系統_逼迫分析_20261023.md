# 東北エリア 上位系統の逼迫状況 分析（2026-10-23）

余野さんの「東北の上位系統がかなり逼迫している」という感触を、リポジトリにある公表データ
（東北電力ネットワークの変圧器・送電線CSV、2026年7〜9月作成分。`grid_cache/` → `data/grid_topology.js`）と
接続検討回答の実績DB（東北40件。`data/connection_results.json`）で確かめた結果です。

## 結論（先に）

1. **感触は正しい。ただし逼迫しているのは「配電用変電所（バンク）」ではなく「その上の275/154kV変圧器と基幹・154kV送電線」。**
   配電用バンク616台の当該空容量は中央値11MWで、2MW未満は5%しかない（関西18%・中国27%・九州32%）。変電所単体では全国でも空いている方。
   一方、上位変圧器27台のうち8台、154/66kV変圧器80台のうち28台（35%）、154kV送電線153本のうち35本（23%）で、
   予想潮流（契約申込済みを含む）が運用容量を超えている。
2. **配電用バンク616台すべてについて、公表の「上位系設備（制約設備）」の中に運用容量を超えた設備が少なくとも1つある。**
   58%は宮城変電所（500/275kV、負荷率101%）を、32%は北東北の安定度フェンス（フェンスNo1・No2）を制約に持つ。
   東北が「出力制御 有り」を98%のバンクに付けているのはこのため（北陸46%・関西41%・四国60%・九州65%）。
3. **実績では、逼迫の表れ方が「出力制御」から「上位変圧器の増強＝数十億円・7〜10年」に変わってきている。**
   2024年の回答は7件中6件が「上位系統増強工事なし」だったが、2025年は27件中13件、2026年（5件）は全件が「あり」。
   増強の理由は「**充電側連系で運用容量超過**」。蓄電池が充電（負荷）する向きで275/154kV変圧器が一杯になっており、
   **公表CSVの予想潮流（発電側の逆潮流）には充電側の空きが載っていないので、公表データでは事前に見抜けない。**
4. **同じ変電所でも後から申し込むと「あり」になる。** 川崎（宮城）は730万円・6ヶ月の回答の後、2026年5月の回答は74.4億円・9ヶ月。
   湊（青森）は2,760万円・14ヶ月 → 1.89億円・25ヶ月 → 41.2億円・16ヶ月（2026年2月）。先行申込で上位系の枠が順番に埋まっている。

## 3. 公表データと実績の食い違い＝東北で気をつけること

- 公表の予想潮流は**発電側（逆潮流）**の値。回答で増強理由になっている「**充電側**（蓄電池が電気を受ける向き）」の空きは公表されていない。
  岩手(変)は公表の負荷率40%、須賀川(変)44%、青森(変)56%なのに、実績では取替・増設が必要と回答されている。
- つまり東北では、**公表データで「上位系に空きがありそう」に見えても充電側で詰まっている可能性があり、接続検討でしか分からない。**
  逆に、公表で100%超の水沢(変)配下（伊手・岩手高田）は実績でも49.9億円と一致している。
- 本体リストの東北のS/A 136件（配電用行で115件）は当該設備の空きだけで付いたランク。上位系の裏付けは無い。

## 4. 次にやること（提案）

1. **上位変電所単位で避ける／狙うを決める。** 岩手(変)・水沢(変)・青森(変)・須賀川(変)・西仙台(変)の配下は、先行者の増強（7〜10年）が終わるまで
   原則見送り。狙うなら「上位系統増強なし」の回答が出た変電所（2-3）と、同じ154/66kV変圧器にぶら下がる近隣。
2. **新潟県を試す。** 本体のS/Aが42件と東北で最多だが実績DBに新潟の案件が1件も無い。制約は東北幹線・本名変圧器（新潟側の逆潮流）で、
   青森・岩手型の「充電側で上位変圧器が満杯」とは別の理由なので、接続検討を1〜2件出して確かめる価値がある。
3. **接続検討は早め・複数地点で。** 同じ変電所でも半年で「なし」→「74億円」に変わった（川崎）。候補地が固まる前に出す。
4. **画面・CSVへの反映（システム側の改善候補、未実施）**
   - 地図・CSVの「上位系の制約設備」に負荷率（予想潮流÷運用容量）を出す。今は設備名と「▼（空き0以下）」だけで、東北は空容量が非公表なので▼が付かず、超過が見えない。
   - 実績DBで名指しされた上位変電所（岩手・水沢・青森・須賀川・西仙台）の配下の配電用変電所に、「上位系で増強回答あり（○○億円）」の警告を出す。
   - 東北のS6エリア点（4点、喜多方の実績が根拠）を、2025〜26年の実績（上位系あり20件・中央値40.8億円）で見直すか判断する。
