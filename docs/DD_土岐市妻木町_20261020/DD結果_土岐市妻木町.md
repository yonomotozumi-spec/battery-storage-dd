## 2. 航空写真の目視（地理院 シームレス空中写真 z17）

- 地点は**樹林に覆われた丘陵の北端**。北側は工場・資材置き場が並ぶ工業地、すぐ東に未舗装の作業ヤード状の空地あり
- → **森林法の確認が最重要**（地域森林計画対象民有林なら、1haを超える開発は林地開発許可、1ha以下でも伐採届）
- 丘陵地のため造成（切土・盛土）が必要になる可能性。盛土規制法（岐阜県は規制区域指定済）の確認要

## 5. 要確認（人が確認する項目）

1. 森林（地域森林計画対象民有林か・保安林でないか）… 岐阜県森林GIS／土岐市農林課
2. 農地（地目）… 樹林地のため可能性は低いが登記簿で地目確認
3. 埋蔵文化財包蔵地 … 土岐市は美濃焼の古窯跡が多い地域。**文化財の確認は特に重要**（ぎふ文化財マップ／土岐市文化振興課）
4. 垂直積雪量・景観・騒音振動・鳥獣保護区
5. 用地の筆が土石流の警戒区域（北側に隣接）に掛からないか
6. 接道・搬入路（丘陵上の樹林のため、北側工業地の道路から進入できるか）

> 自動判定はスクリーニング補助です。最終確認は各行政窓口・現地で行ってください。
