## 次のアクション（優先順）

1. **上ノ国町 大安在（E）**：町（農業委員会・産業振興課）に農用地区域の指定状況と農振除外の見込みを確認。
   北電ネットワークに上ノ国変電所の実位置・空容量（上位系考慮）を事前相談。
2. **遠別町 丸松（F）**：開発面積を1ha以下に抑える配置を検討（林地開発許可・開発許可の回避）。系統は北電NWへ事前相談。
3. **位置不明の6筆（B・G）**：法務局で公図の写し・地積測量図を取得。
4. A・Cは見送り推奨（A のうち館浜4筆 No.1〜4 は農用地区域の外。単独で使う場合のみ再検討）。

## どう調べたか

- **位置**：住所に座標が無いため、法務省の登記所備付地図（G空間情報センター 2026年版）から地番ごとの筆ポリゴンを取り出した。
  45筆中39筆で位置を特定。公図面積は登記地積とほぼ一致（差が15%を超えたのは神山30・147、札前372-16のみ）。
- **土地利用規制**：国土数値情報（土地利用基本計画2015・都市地域2018・鳥獣保護区2015・国有林2019）を筆ポリゴンと重ね合わせ。
  3町とも**都市計画区域外**（市街化区域・調整区域・用途地域は該当なし）。
- **災害**：国土地理院 重ねるハザードマップのタイル（洪水・高潮・津波・土砂災害）を筆内の複数点で判定。
- **不動産情報ライブラリ**（国交省、2026-10-19取得）：都市計画・洪水・高潮・津波・土砂災害・液状化・自然公園・大規模盛土・地すべり防止区域・急傾斜地崩壊危険区域を判定し、境界にかかる筆は筆の形との重なりも確認。
  上の結果と食い違いは無し。新たに分かったのは液状化の傾向（札前372-15・372-26が「液状化しやすい」、高野110-2付近が「やや液状化しやすい」、他は「液状化しにくい」）。大規模盛土・地すべり防止区域・急傾斜地崩壊危険区域は全筆該当なし。
- **系統**：本リポジトリの全国変電所リスト（66kV以上）から最寄りを算出。

## 注意点

- 国土数値情報は1/2.5万〜1/5万精度で時点も古い（農用地区域は2002〜2006年）。**境界付近の判定は町・道の最新図面で必ず確認**してください。
- 北海道エリアの変電所は元リストの座標が「推定」で、空容量（上位系考慮）も未公表のため、系統スコアは算出できません。
- 垂直積雪量・埋蔵文化財・景観・騒音振動はチェックシートのリンクから確認してください。
- 液状化は地形区分にもとづく「傾向」で、地盤調査の代わりにはなりません。
- 自然公園名はデータに入っていないため、位置から松前矢越道立自然公園（松前町）・檜山道立自然公園（上ノ国町）と推定しています。
