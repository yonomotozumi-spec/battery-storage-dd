## 2. 案件別の所見

### A. にかほ市象潟町小滝字旭塚28-3
- **都市計画**：都市計画区域**外**（最寄の区域界まで約717m）。用途地域・区域区分の指定なし。
  → 開発許可は1ha以上の開発行為で対象。
- **ハザード**：洪水・高潮・津波の浸水想定区域いずれも**該当なし**。土砂災害警戒区域も**該当なし**
  （ただし約700m西南西に土石流「大境沢2（Ⅱ-1614）」の警戒区域・特別警戒区域あり）。
- **液状化**：しにくい（火山山麓地／傾向5段階中5）。
- **自然公園**：区域外。**鳥海国定公園の区域界まで約1.0km（南南東）**。事業区域の最終形が掛からないか要確認。
- **積雪**：秋田県は秋田市・横手市を除く県内全域が多雪区域。指定値はにかほ市建築担当へ照会。
- **系統**：象潟変電所 約2.5km（66kV／空容量9MW／N-1電制 不可#4／出力制御あり／ランクB）。
  次点 由利変電所 約4.0km（154kV）。総合40点（Cランク）。
- **現況**（依頼者情報）：概ね更地・周辺民家なし。→ 造成費・近隣リスクとも軽い想定。

### B. 鹿角市花輪字柴内太田谷地24-1他
- **都市計画**：座標点は**都市計画区域の内側**（秋田県告示第711号）。ただし**区域区分の定めなし＝非線引き**。
  → **開発許可の規模要件が3,000㎡以上に下がる**（都計法29条1項1号）。BESS用地は通常この規模を超えるため、
  開発許可「要」となる可能性が高い。許可権者（秋田県）へ最優先で事前照会。
- **用途地域**：座標点は指定なし。最寄の第一種低層住居専用地域（建蔽率50%／容積率80%）まで約493m。
- **ハザード**：浸水**該当なし**。土砂災害警戒区域も座標点は**該当なし**。
  ただし約366m南東に土石流「蟹沢（Ⅱ-0032）」の警戒区域があり、**その関係地名に本件の字名「柴内太田谷地」が含まれる**。
  同一流域のため、筆全体・進入路が区域に掛からないか秋田県砂防担当へ必ず照会すること。
- **液状化**：やや しにくい（扇状地）。ただし「谷地」は低湿地由来の地名で、軟弱地盤の可能性あり → 地盤調査推奨。
- **農地**：「太田谷地」の字名から**農地（田）の可能性が高い**。地目・現況・農振農用地区域（青地）該当を
  鹿角市農業委員会へ照会。青地なら農振除外（通常6ヶ月〜1年）が工程のクリティカルパスになる。
- **積雪**：多雪区域。指定値は鹿角市建築担当へ照会。
- **系統**：**花輪変電所 約0.6km**（66kV／空容量20MW／N-1電制 不可#4／出力制御あり／ランクA）。
  次点 毛馬内変電所 約7.5km（空容量22MW・ランクA）。総合63点（Aランク）＝3案件で最良。
  変電所が近く新設延長が短いため、負担金（≒400万円＋0.8〜1.0万円/m）を抑えられる可能性。
- **現況**（依頼者情報）：民家まで約50m、母屋との間に納屋。
  → PCS・空調の**夜間騒音が最大の近隣リスク**。離隔・防音壁・機器配置を初期レイアウトで織り込むこと。

### C. 北広島町川小田10059-3
- **都市計画**：都市計画区域**外**。用途地域・区域区分の指定なし。→ 開発許可は1ha以上で対象。
- **ハザード（要注意）**：座標点は非該当だが、**約82m北北西に土砂災害警戒区域、約88mに土砂災害特別警戒区域**
  （いずれも急傾斜地の崩壊「川小田(7530)」2019/8/29指定）。事業区域・進入路が特別警戒区域に掛かると
  **特定開発行為の許可**（土砂災害防止法）が必要。広島県西部建設事務所で区域図を必ず確認。
- **浸水**：洪水・高潮・津波いずれも該当なし。**液状化**：やや しにくい（谷底低地）。
- **大規模盛土造成地**：約1.26kmに谷埋め型（北広島町0006）。敷地は非該当。
- **垂直積雪量：約2.0m（概算）**。広島県建築基準法施行細則第12条の3の算定式 d=α(ls−lso)+do に、
  旧芸北町の公表値（lso=589m・do=2.05m・α=0.0036）と現地標高575.6mを代入して算出。
  → **基礎・架台の積雪荷重、除雪動線、冬季アクセスがコストに直結**。北広島町建設課で最終確認のこと。
  （案件地は北広島町役場芸北支所〈川小田10075-5〉のすぐ近くで、旧芸北町域であることは住所・郵便番号からも確認。）
- **系統（最大リスク）**：最寄 芸北変電所 約4.1km（110kV）は**空容量0（上位系考慮・当該設備とも）＋N-1電制不可**で、
  社内スコアリングのゲート条件（上位系増強リスク）に該当し**「除外」ランク**。次点の下山変電所 約6.1kmも同条件。
  総合17点（Cランク）。→ **用地を進める前に中国電力ネットワークへ空容量の最新状況・増強見通しを確認すべき。**
- **現況**（依頼者情報）：概ね更地・周辺民家なし。

## 3. 条例リスク照合（`data/ordinance_registry.json` 2026-08-21時点）

- **秋田県**：県としての系統用蓄電池の開発許可運用は**公表確認できず**。ただし県内の**潟上市**が
  「危険物含有の蓄電池コンテナ＝第一種特定工作物／複数積みは建築物」として運用を公表済み（2025-12-03）。
  同種の運用が他市町村へ波及する可能性があるため、にかほ市・鹿角市とも都市計画担当へ事前照会が必要。
- **広島県**：県としての公表は**確認できず**。ただし県内の**呉市**が運用基準を公表済み（2026-02-10）。
  北広島町・広島県西部建設事務所へ事前照会が必要。
- **国（共通）**：国交省 技術的助言（国都計第7号）により、危険物を含有する系統用蓄電池は第一種特定工作物として
  開発許可の対象になりうる。案件進行中に「開発許可が必要」へ運用変更されるリスクの引き金。
- **消防**：全案件で所轄消防への事前協議が必須（火災予防条例／許認可No.37）。

## 5. 自動判定の範囲と限界

- **自動で入った項目**：住所・座標／浸水（洪水・高潮・津波）／土砂災害／液状化／市街化区域／市街化調整区域／
  用途地域／自然公園（reinfolib XKT001,002,016,019,020,021,022,025,026,027,028,029）。Cの垂直積雪量は広島県の公表算定式から算出。
- **人が確認する項目**：架線の敷地内縦横断／垂直積雪量（A・B）／農地／森林／鳥獣保護区／埋蔵文化財／景観／騒音／振動。
  各シートのF列に座標直リンク・検索リンクを用意済み。
- **限界**：判定は「入力された1点の座標」に対するもの。**筆（土地の区画）全体では結果が変わりうる**。
  特にCの土砂災害区域（82m）とBの土石流流域は、筆界図と区域図を重ねた確認が必須。
- reinfolibに農地・森林・鳥獣保護区・埋蔵文化財のレイヤは無いため、これらは自動化できない。
