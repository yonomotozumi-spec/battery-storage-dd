# 特別高圧連系 蓄電所用地開発ガイドライン 検討メモ（たたき台）

作成日: 2026-10-06 ／ ベース: 「蓄電所用地開発ガイドライン v1.05」（高圧連系版・2025-09-15改訂）

> このメモは、高圧版ガイドラインを特別高圧（特高）連系の蓄電所に広げる場合に、
> **どの条文がそのまま使えて、どこを変える・足す必要があるか**を整理したもの。
> 数値は議論のためのたたき台で、EPC・輸送会社・一般送配電事業者・社内での確認が前提。
> 【要確認】は法令の閾値や運用など、一次情報で裏取りが必要な箇所。

---

## 1. 前提：特高版で最初に決めること

高圧版は「送電端2,000kW未満・8〜10MWh・Mega Power 3〜4台」という**単一の標準仕様**を前提に、
面積・土地代・負担金を固定値で定めている。特高は規模の幅が大きいため、まず規模帯を決めないと各基準が決まらない。

| 論点 | 選択肢 | コメント |
|---|---|---|
| 想定規模帯 | (a) 2〜10MW（22/33kV中心） (b) 10〜50MW（66/77kV中心） (c) 両方を段階別に定義 | 10MW以上は発電事業届出の対象になり手続きが一段増える（後述）。(c) を推奨 |
| 標準ユニット構成 | 例：Mega Power ×N台＋PCS＋主変圧器＋特高受変電設備 | 面積・地耐力・輸送台数の計算根拠になる。EPCと標準レイアウトを1〜2パターン作る |
| 基準の持ち方 | 固定値 or **kW/kWh当たり単価** | 土地代・負担金は規模比例にしないと案件間で比較できない |
| 対象電力エリア | 高圧版は北海道・沖縄を除外 | 特高で北海道を対象にするか（寒冷・積雪基準とセットで判断） |

## 2. 条文ごとの比較（高圧版 → 特高版）

| 条 | 高圧版 v1.05 の基準 | 特高で変わる点 | 特高版のたたき台 |
|---|---|---|---|
| 第一条 目的・仕様 | 送電端2,000kW未満、8〜10MWh、Mega Power 3〜4台 | 規模が可変。受変電設備が加わる | 「送電端2,000kW以上、特別高圧（22kV以上）連系」。規模帯ごとに標準構成を別表で定義 |
| 第三条(1)(2) 面積 | 設置500〜600㎡・作業700〜1,100㎡（短辺条件付） | 台数×単位面積＋**特高受変電エリア**＋離隔・調整池・緑地 | 「標準レイアウト面積×1.2以上」の形で定義。目安：1台あたり約150〜200㎡（高圧版の設置面積からの逆算）＋受変電 1,000〜2,000㎡（66kV級）【要EPC確認】→ 20MW/80MWh級で概ね0.8〜1.5ha |
| 第三条(4) 機器間隔 | 3m以上（地域の消防ルール優先） | 台数が多く、延焼防止の考え方が重要に | 同じ3m以上を基本に、**ブロック間の延焼防止離隔**を所轄消防と協議する旨を追記 |
| 第三条(5) 上空電線 | 横断電線がないこと | 特高引込線（架空 or 地中）の取り回しが加わる | 横断電線なし＋**一般送配電の引込点（鉄塔・ケーブルヘッド）を設置できる位置関係**であること |
| 第三条(6) 搬入口 | 1車線15m／2車線8m、段差10cm、傾斜8° | 変わらない（Mega Powerは同じ）。ただし**主変圧器の輸送**が新たに入る | 同基準を維持＋主変圧器の重量・寸法での搬入可否を別途確認 |
| 第三条(7) 騒音 | 法令・条例適合、規制なしでも民家50m以上 | PCS台数増＋**主変圧器のうなり（低周波）**。音源が多く「点音源1つ」の計算では不足 | 騒音予測を音源ごとの合成で行う。民家離隔は**100m以上**を目安（たたき台）。振動・低周波も確認項目に追加 |
| 第四条 住民理解・景観 | 再エネ調和条例の遵守、説明会ガイドライン参考 | 規模が大きく目立つ、住民の関心も高い | **説明会の実施を原則必須**化。条例リスク台帳（`docs/条例リスク台帳.md`）での事前照合を明記 |
| 第五条(1) 林地開発等 | 1ha以上で林地開発許可 等 | 特高案件は1haを超えやすく、**林地開発許可が現実に当たる**。許可取得に半年〜1年 | 条文は同じでよいが、「1ha超の森林を含む候補は原則スケジュール評価を厳しく」等の運用を追記 |
| 第五条（新設） 都市計画法 | **記載なし** | 国交省技術的助言（国都計第7号・2025-04-08）で、蓄電池を**第一種特定工作物**として開発許可の対象とする自治体が増加。面積が大きい特高ほど影響大 | 「開発許可の要否を、許可権者（都道府県・政令市等）に事前確認しメール証跡を残すこと」を新設。※高圧版にも追加推奨 |
| 第五条(2) 農地転用 | 農地法5条、農振は難度高 | 面積が大きいほど転用許可権者が上がる（4ha超は国協議）【要確認】 | 同じ＋面積による許可権者・審査期間の違いを注記 |
| 第五条(3) 埋蔵文化財 | 包蔵地に該当しないこと | 面積が大きいと試掘調査を求められやすい | 同じ（包蔵地外）＋**隣接・近接の場合は試掘協議の要否を確認** |
| 第六条(1) ハザード | 浸水0.5mまで、警戒区域外、PL値5未満 | **受変電設備（変圧器・GIS）は浸水に弱く**被害額も大きい | 浸水基準は維持しつつ、受変電設備は**かさ上げで想定浸水深＋余裕**を確保できること |
| 第六条(2)(3) 気温・積雪 | -20℃以下が50年で3日以内、積雪150cm未満 | 機器は同じなので基本同じ。北海道を対象にするなら見直し | 同じ（北海道を入れる場合は寒冷地仕様の可否をメーカー確認） |
| 第七条 搬入経路 | 幅員3m、回転半径7m、高さ3.8m、二等橋 | Mega Powerは同じ。**主変圧器（数十t級）は別の特殊車両が必要**になりうる。台数が多く輸送回数も増える | Mega Powerの基準は維持＋**主変圧器の輸送ルート確認**を追加。輸送回数が多いため、生活道路を長く通るルートは住民説明の論点になる |
| 第八条 地耐力 | 30kN/㎡以上、SWS試験 | 主変圧器・GIS基礎は荷重が集中。敷地が広く地盤のばらつきも出る | 30kN/㎡以上を維持＋**受変電基礎の位置でボーリング等**。SWS試験は敷地内の複数点 |
| 第九条 土地代 | 売買900万円以下、地上権38.5万円/年以下 | 規模比例にしないと判断できない | **円/kW または 円/㎡** で上限を設定（例：高圧版の900万円÷2,000kW＝約4,500円/kWを出発点に議論） |
| 第十条(1) 負担金 | 10,000円/kW以下 | 特高は変電所・送電線の増強が絡み、金額の振れ幅が大きい | 上限をkW当たりで設定しつつ、**自営線（送電線）・受変電設備の自社負担分**も合算して評価 |
| 第十条(3) アクセス工期 | 原則18か月以内 | 66kV以上の増強は数年単位になりやすい | 規模帯ごとに設定（例：22/33kVは24か月、66kV以上は36〜48か月を上限のたたき台）。**ノンファーム型・出力制御**の扱いも追記 |
| 第十一条 消防法 | 「蓄電池設備の関連規定」に則る | 大容量で、電解液が**危険物の指定数量**に関係しうる【要確認】 | 所轄消防との事前協議を開発着手前に必須化 |
| 第十二条 電力エリア | 東北〜九州の8エリア | 北海道を入れるかが論点 | 1章の論点で決定 |
| 第十三条 反社排除 | — | 変わらない | 同じ |

## 3. 特高版で新しく必要になる条文

高圧版には無いが、特高では避けて通れない項目。

1. **自営線・引込ルート**
   一般送配電事業者の変電所・送電線から敷地までの距離、自営線の敷設ルート（地中／架空）と、
   その**ルート上の地権者の承諾（地役権・道路占用）**が見込めること。距離が長いと費用・工期・用地交渉が膨らむ。
   既存の変電所スコアリング（`substation.html`）の「近接スコア」が判断材料になる。
2. **電気事業法上の手続き**
   - 放電出力が1万kW以上の系統用蓄電池は**発電事業の届出**の対象（2022年の法改正）【要確認：最新の閾値】
   - 一定規模以上の蓄電所は**工事計画の届出**が必要【要確認：出力・容量の閾値】
   - 保安規程の届出、**電気主任技術者の選任**。7,000V超の設備は保安業務の外部委託ができないため、
     選任（統括事業場の活用等）を前提にした運用コストを見込む【要確認】
3. **特高受変電設備のスペース・保安**
   主変圧器・開閉設備の配置、フェンス・離隔、保守車両の動線を標準レイアウトに含めること。
4. **環境関連**
   蓄電所は環境影響評価法の対象事業ではないが、**自治体の環境影響評価条例・景観条例**で
   造成面積等により対象になる場合がある【要確認：自治体ごと】。
5. **スケジュール・事業性の基準**
   特高は系統・許認可ともに長期化しやすいため、「接続検討回答〜運転開始までの想定期間」を
   ガイドラインの評価項目として明記する（市場参入の時期や制度の募集時期との整合）。

## 4. 高圧版 v1.05 自体の改訂候補（ついでに見つかった点）

特高版を作る際に、高圧版も合わせて直しておくとよい点。

- **都市計画法（開発許可）の記載が無い**：国都計第7号（2025-04-08）以降、市街化調整区域等で蓄電池を
  第一種特定工作物として扱う自治体が増えている（`docs/条例リスク台帳.md` 参照）。第五条に追加推奨。
- 第一条(1)「順調および逆潮」→「順潮流および逆潮流」の誤記と思われる。
- 第六条(1)「国土交通町」→「国土交通省」の誤記。
- 第十三条が2つある（反社排除と改訂）。改訂は第十四条に。
- 参考1（騒音の環境基準）・参考11（道路通行車両の制限）が本文から参照されていない。
- 第九条（土地代）が第二条の「考慮すべき事項」一覧に無い。

## 5. 次の進め方（案）

1. 社内で**1章の論点**（規模帯・基準の持ち方・電力エリア）を決める
2. EPCに**標準レイアウト**（例：10MW/40MWh、30MW/120MWh の2パターン）を作ってもらい、面積・地耐力・受変電の数値を確定
3. 【要確認】箇所（電気事業法の閾値、消防・危険物、農地転用の許可権者）を一次情報で裏取り
4. 条文化して特高版ガイドライン v0.1 を作成
5. DDチェックツール（`index.html`）に「高圧／特高」の切替を設け、ガイドライン基準での自動判定に反映
